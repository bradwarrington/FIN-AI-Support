How to test

  1. Ask real questions. Use things customers actually ask, like how-to questions, login or access problems, email notifications, or forms.
  2. Try one topic per chat. Start a new conversation for each scenario so it's easier to review afterwards.
  3. Push back. Say the answer didn't work, give vague details, or change your mind. See whether Fin asks sensible follow-up questions and offers an Analyst when it's stuck.
  4. Check the answer. Is it correct for ThoughtFarmer? Does it link the right Help Center article? Does it assume your setup (hosting, sign-in, groups) without asking?
  5. Test the handoff with care. Asking for a person creates a real Zendesk ticket. Start that message with TEST so Support knows to close it.
  6. Keep it safe. Don't enter passwords, customer data, or anything confidential.
