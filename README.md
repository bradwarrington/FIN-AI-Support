# Fin chat test page

A temporary test page that hosts ThoughtFarmer's Intercom Fin chat widget, so the Support team can try Fin with real users before it goes on our own Help Desk site.

- **Status:** test only, not a production site
- **Owner:** Bradley (Support)
- **What's here:** one static `index.html` that loads the Intercom Messenger. There's no backend and no sensitive data.

Please check with Support before changing or removing this repo.
